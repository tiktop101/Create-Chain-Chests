# Create: Chain Chests

**Create: Chain Chests** is an addon for Create that lets you attach storage blocks to chain conveyors and transport them around.

### Features
- Attach chests, barrels, and shulker boxes to chain conveyors.
- Support for **Sophisticated Storage**.
- Support for **Storage Drawers**.
- Build your own storage transport systems using Create's chain conveyors.

Move your storage, connect your systems, and transport your items with Create: Chain Chests!
